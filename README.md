# Portfolio - Ajeng Sumawi
NIM: [0243001007]

## Deskripsi Project
Project ini adalah website portfolio pribadi yang dibangun sebagai tugas UTS. Website ini menampilkan profil, keahlian, pengalaman, dan daftar project.

## Cara Menjalankan Project
1. Clone repository ini: git clone https://github.com/ajengsumawi077-spec/UTS-Personal-Page.git
2. Masuk ke folder: cd UTS-Personal-Page
3. Install dependencies: npm install
4. Jalankan aplikasi: node backend/app.js
5. Buka http://localhost:3008 di browser.
